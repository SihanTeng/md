md package repositories

Static APT and DNF repos for md, published from GitHub Releases (no third-party account). Current version: 0.3.0.

Debian / Ubuntu (APT)

echo "deb [trusted=yes] https://sihanteng.github.io/md/apt ./" | sudo tee /etc/apt/sources.list.d/md.list
sudo apt update
sudo apt install md

Fedora / RHEL (DNF)

sudo tee /etc/yum.repos.d/md.repo <<'EOF'
[md]
name=md
baseurl=https://sihanteng.github.io/md/rpm
enabled=1
gpgcheck=0
EOF
sudo dnf install md
